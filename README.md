# First Light

A tiny robot stands alone on a dark rocky cliff edge, one arm raised in
awe, facing a colossal golden sun rising through dramatic rose, violet,
and gold clouds.

The twist is simple: a machine experiencing wonder. The robot is small
against an enormous sky, the sun is rising, the rays are bursting, and
the raised arm is the first gesture of something that has just woken up
to the world.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to `out/entry.png` and checks that the copied
file is at most 1 MiB.
